# AI 广告投放诊断助手

一个用于作品集演示的本地应用。用户上传虚构广告数据 CSV 或 Excel，应用计算广告指标、展示图表，并生成初步诊断和 AI 建议。

项目需求与当前交付说明见 [PRD v1.2](AI%20广告投放诊断助手%20PRD%20v1.2.md)。

## 功能

- 上传并预览 CSV 或 Excel（`.xlsx`）广告数据；Excel 文件可选择工作表
- 自动识别常见中英文列名，并允许用户确认字段对应关系
- 支持投放人群、落地页版本、素材类型、投放位置和投放目标等可选分类列
- 按广告系列汇总数据
- 按曝光到点击、点击到页面浏览、访问用户到付费用户展示分阶段转化指标
- 可按一个影响因素分组比较指标
- 下载包含广告系列汇总、各影响因素分表和 AI 诊断建议的 Excel 分析结果
- 计算 CPM、CPC、CTR、Click-PV rate、CPPV、Cost/DAU、CPUV、Paid UV Rate 和 ROAS
- 对比广告系列的 ROAS
- 生成规则诊断和 AI 诊断建议
- AI 诊断按“数据观察、可能原因（待验证）、下一步建议”组织，并要求引用指标和比较对象
- AI 诊断按相同阶段、相同指标口径比较广告系列和影响因素分组

## 上传数据列

必需列是广告系列名称、花费、曝光次数和点击次数。系统能识别常见的中英文列名，例如 `campaign_name`、`Campaign name` 或“广告系列名称”都可以对应广告系列名称；“花费”或 `Cost` 可以对应花费。

支持 CSV 和 Excel（`.xlsx`）文件。Excel 文件上传后，先选择要分析的工作表，再确认字段。飞书表格可先导出为 Excel 或 CSV 再上传；应用不会直接连接飞书账号。旧版 `.xls` 暂不支持。

投放周期（天）、PV、UV、Paid UV、GMV，以及投放人群、落地页版本、素材类型、投放位置和投放目标都是可选列。周期列可使用 `duration_days`、`Day` 或“投放天数”等名称；它会作为周期说明显示，不会参与指标求和。DAU 由 UV ÷ 投放周期自动计算，不再从 CSV 读取 DAU 列；因此计算 DAU 和 Cost/DAU 需要同时提供 UV 和投放周期。如果文件中出现多个周期，应用会让用户选择统一输入一个周期，或跳过 DAU 和 Cost/DAU。分类列可用于“影响因素”页的分组对比。

上传后，用户可以检查并调整系统识别的列对应关系。未选择的额外列会保留在原始数据预览中，但不参与分析。被选作数值字段的列必须是数字。

CSV 优先读取 UTF-8 编码；如果识别失败，会尝试 GB18030 编码。Excel 上传和结果导出需要 `openpyxl`，首次使用时按本地运行步骤重新安装 `requirements.txt` 中的依赖。

## 本地运行

在项目文件夹中打开 PowerShell，首次运行时依次执行：

```powershell
py -3.13-64 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## AI 接入与密钥说明

公开体验时，每位使用者需要在 AI 诊断区域填写自己的 OpenAI API Key；API 费用由该密钥所属账户承担。应用会显式使用本次填写的密钥，不使用应用所有者的默认密钥。建议使用权限受限并设置支出限制的 API 项目密钥。

密钥通过 HTTPS 发送到运行应用的 Streamlit 服务器，仅用于本次 OpenAI 请求，不写入项目文件或数据库；表单提交后会清空输入框。由于服务器需要使用密钥发起请求，请只在信任本应用时输入。AI 请求会发送广告系列与已确认影响因素的汇总指标（包括广告系列名、因素分组名、UV 和 Paid UV 汇总人数），不发送逐行原始记录；每种因素最多发送花费最高的 10 组。

使用者需要拥有可用的 OpenAI API 账户和 API 额度。ChatGPT 订阅不替代 API 额度。

## 指标公式

- CPM = 花费 ÷ 曝光次数 × 1000
- CPC = 花费 ÷ 点击次数
- CTR = 点击次数 ÷ 曝光次数 × 100%
- Click-PV rate = 页面浏览次数 ÷ 点击次数 × 100%
- CPPV = 花费 ÷ 页面浏览次数
- DAU（日均）= 周期 UV ÷ 投放周期天数
- Cost/DAU = 花费 ÷ DAU（日均）
- CPUV = 花费 ÷ 访问用户数
- Paid UV Rate = 付费用户数 ÷ 访问用户数 × 100%
- ROAS = 成交金额 ÷ 花费

漏斗中的 Click-PV rate = 页面浏览次数 PV ÷ 点击次数 × 100%，PV 是浏览次数，可能高于点击次数；UV 和 Paid UV 是去重人数。因此应用将其作为分阶段指标展示，不把这些口径不同的数字误认为严格连续、必然逐层递减的用户漏斗。

## 数据说明

项目中的示例数据为虚构数据，不连接真实广告账户。样例共 18 行，每一行表示一个广告组合在 7、8 或 10 天投放周期内的汇总值，不是逐日记录。由于周期不一致，使用者需要选择统一计算周期，或跳过 DAU 和 Cost/DAU。这里的 UV 按周期内每日 UV 累计口径填写，DAU（日均）按 UV 除以选定周期天数估算。影响因素分组只用于观察数据中的差异，不能单独证明某个因素造成效果变化；实际业务中应通过控制其他条件的对照测试验证。
